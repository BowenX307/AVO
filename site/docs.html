Using AVO

Tap right ⌥, say what you want done, and answer when AVO points back — with a word. This page covers everything from install to the first task.

01Requirements

  • macOS 15 (Sequoia) on Apple silicon. That’s what AVO is built and tested on (15.5); older versions are untested.
  • A Meta Model API key from dev.meta.ai.
  • Python 3.11+ with uv, and Node.js (tested with 24) for the on-screen overlay.
  • Four macOS permissions, for the app you start AVO from (Terminal, iTerm, VS Code…):
    • Screen Recording — to see the screen.
    • Accessibility — to click and type, and to read buttons, fields and names on screen (near-miss clicks snap onto them; names help AVO hear you).
    • Input Monitoring — for the summon key (a tap of right ⌥), and to notice when you take over the mouse or keyboard.
    • Microphone — for spoken tasks and answers. macOS asks the first time you tap right ⌥.

02Install

Download for macOSA packaged app (DMG) isn’t available yet — for now, AVO runs from source. When the DMG ships unsigned, the first open needs right-click → Open, then Open again in the dialog.

From source

git clone https://github.com/BowenX307/AVO.git
cd AVO
uv sync                         # Python side: the agent
cp .env.example .env            # then put your key after MODEL_API_KEY=
cd overlay && npm install       # the on-screen overlay (Electron)

The key can also live in the MODEL_API_KEY environment variable. .env is git-ignored; never commit your key.

03First run

  1. Grant the permissions. System Settings → Privacy & Security → Screen Recording, Accessibility and Input Monitoring: add the terminal app you’ll start AVO from, then quit and reopen it. Microphone is asked for the first time you speak to AVO.
  2. Check the key. 
    uv run scripts/smoke_api.py     # expects: AVO smoke test OK
  3. Start the overlay. A small black capsule appears at the top of the screen and draws the AVO logo. 
    cd overlay && npm start
  4. Run a test task. Open demo/mail.html in Chrome, tap right ⌥ and say Reply to Professor Smith, say I’ll be ten minutes late. Or click the capsule and type it. Or from the terminal: 
    uv run scripts/run_task.py "Reply to Professor Smith, say I'll be ten minutes late."

The demo pages in demo/ — a mailbox with two Professor Smiths, study-room bookings, a course page with two near-identical handouts, a project board, an expense form — use made-up data and are safe to practise on. uv run scripts/run_demo.py runs the first three again and again, with a script answering for you.

04How to use

  1. Summon

    Tap right ⌥ once — a tap, not a hold. The capsule at the top of the screen opens and says Listening.

    Screenshot neededThe capsule open, reading “Listening”

  2. Say it

    Say what you want done, as you’d ask a person: Reply to Professor Smith, say I’ll be ten minutes late. The words appear in large type as you speak. Stop talking, or tap right ⌥ again, and AVO starts.

    Clip needed · 3–5 sThe sentence appearing in large type

  3. Answer with a word

    When more than one thing fits, AVO rings each with a number and asks. Say two, the physics one or none of these, press the number, or click the right spot yourself.

    Clip needed · 5–10 s“Which one did you mean?” — the two Smiths ringed; “two”

  4. Say yes before anything final

    Before sending, submitting, deleting, paying or booking, AVO shows what it will do — the reply it wrote, say — and waits for yes. Say stop, or tap right ⌥, any time.

    Screenshot needed“Send — OK?” with the drafted reply

  5. Or type, or box it

    Click the capsule and type the task instead. To point at something first, press ⌥ Space and drag a rough box over it (A), and over where it goes (B) if anything goes somewhere; SAM 3.1 finds what you meant inside the box.

    Clip needed · 3–5 sDragging a rough box A over a note, B over a card, and typing one line

07Privacy & safety

What leaves your Mac

  • Screenshots of your screen (without AVO’s own overlay), your typed task and the boxes you drew go to the Meta Model API (api.meta.ai) — nowhere else.
  • AVO calls muse-spark-1.3 in Standard mode. Meta’s docs say Standard-mode content isn’t used to train Meta models. Targets are found with sam-3.1, which Meta’s docs don’t place in either mode.
  • When you speak to AVO, your voice — only while the island shows it’s listening — and names read from the front window (button labels, names on the page, which help recognition) go to Meta’s speech recognition, muse-voice-transcribe-1.0.
  • Turn on Do Not Disturb before a task: a notification that pops up gets into the screenshots.

What stays on your Mac

  • Each run is logged to runs/<time>/: the screenshots, the model’s steps and your answers. Delete the folder any time.
  • Your API key, in .env or the environment.

Safety checks

The model can attach safety checks to an action. Meta attaches a routine one, computer_action_requires_confirmation, to almost every action. AVO doesn’t acknowledge it silently: before the action it rings the target on screen and counts down one second, and saying “no” (or pressing Cancel) calls it off. The countdown stands in for your review only if the ring was really drawn — when there is nothing to ring, or the overlay isn’t running, AVO asks for a yes instead (in the terminal, without the overlay).

Actions that can’t be undone — sending, submitting, deleting, paying, booking — and every other check code (for example malicious_instructions) show a preview, such as the reply about to be sent, and wait for your “yes”. Every confirmation is written to the run’s log: the check codes, how it was confirmed, and whether you said no.

Staying in control

  • Before an uncertain click, AVO shows you the target and asks.
  • Touch the mouse or keyboard and AVO pauses within a fraction of a second. It doesn’t click while paused, and after Resume it looks at the screen again before acting. For a spoken task only a click counts, so an unintended nudge of the mouse doesn’t stop it; say “stop” or tap right ⌥ instead.
  • Before each click it compares the target area with what the model saw; if it changed, the click is skipped and the model decides again.
  • ⌥ Space pauses, Stop ends the task, and the pointer in a screen corner stops it at once.

08Troubleshooting

A permission doesn’t take effect

macOS grants permissions to the app that starts AVO — your terminal, not Python. Add that app in each of the three lists, then quit and reopen it. Without Input Monitoring AVO still runs, but only notices you switching apps, not touching the mouse.

Clicks land a little off

AVO already snaps a near-miss onto the closest button or field within 36 points, and asks when two are equally close. Keep the page at 100% zoom, don’t move or resize the window mid-task, and when it asks, click the right spot — it uses your point.

API errors

  • MODEL_API_KEY is not set: put the key in .env or export it in the shell that starts AVO.
  • 401 / 403: the key is wrong or revoked — make a new one at dev.meta.ai and run scripts/smoke_api.py.
  • A step that hangs: a model call can occasionally take much longer than usual. Press Stop and run the task again.

The overlay doesn’t appear

Another program may hold its port (8765). Start the overlay with AVO_OVERLAY_PORT=8766 npm start and set the same variable for the agent.
